# MealCard-Management-System-C
 
项目简介
 
本项目为C语言结构化控制台课程设计程序，模拟校园食堂饭卡日常管理业务，采用文件持久化存储数据，实现饭卡开户、充值消费、信息查询、挂失注销、数据存档等完整校园一卡通管理逻辑。
程序界面简洁清晰、交互逻辑规范，无图形界面，纯控制台字符交互，代码结构规范、模块化编写，适合C语言基础实训、课程设计作业使用。
 
开发环境
 
- 开发语言：C语言
​
- 运行平台：Windows 系统
​
- 编译软件：Dev-C++ / Visual Studio / VS Code
​
- 程序类型：控制台应用程序
​
- 数据存储：本地文本文件持久化保存，关闭程序不丢失数据
 
核心功能
 
1. 饭卡开户、新用户信息录入

​2. 饭卡余额充值、食堂消费扣费

​3. 个人余额查询、消费流水记录查看

​4. 饭卡挂失、解除挂失、卡片注销

​5. 用户信息修改、管理员权限操作

​6. 批量数据读取、文件自动保存

​7. 菜单循环交互、异常输入容错处理
 
项目特点
 
- 模块化函数编写，逻辑清晰易读
​
- 控制台友好菜单交互，操作简单直观
​
- 文本文件读写，实现数据长期持久化
​
- 基础异常判断，防止余额不足、重复挂失等错误操作
​
- 代码规范整洁，结构易懂，便于二次修改与扩展
 
运行方式
 
1. 将源码文件导入C语言编译环境

​2. 直接编译运行生成可执行文件

​3. 在控制台按照菜单提示输入序号操作即可

​4. 程序自动保存所有饭卡数据至本地文件
